Bookmarks

Saves links to your own Bookmarks app. Nothing goes anywhere else.

Connect this browser

Enter your Bookmarks address. On this computer it is usually http://127.0.0.1:4316. Bookmarks will ask you to allow this browser, the same way it asks any assistant. Choose Only add: the extension only saves links, so it never needs to read what you saved.

Connected

Cmd+D sends the link and title, and Bookmarks reads the page when it can. The toolbar button, or Alt+Shift+S, also saves the text you can see, including behind a login.

Bring in what is already here

Folders become tags. Links already saved merge, so this is safe to repeat.
